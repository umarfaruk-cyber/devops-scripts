# Devops Bash Scripting Exercises

A collection of Devops automation scripts written in Bash.

## Scripts Included

-sysinfo.sh - System Information reporter
-user_profile.sh - User profile creator
-bulk_users.sh - Bulk user management
-project_setup.sh - Project directory generator
-functions_lib.sh - Reusable functions library
-use_functions.sh - Functions library usage example
-backup_system.sh - Automated backup system
-health_monitor.sh - Server health monitor
-deploy.sh - Deployment pipeline simulator
-system_audit.sh - Full system audit reporter
